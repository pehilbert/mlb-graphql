# MLB GraphQL

A GraphQL server for the official MLB Stats API, aimed to simplify interaction with the API for use in open-source projects.

This project is very much a work in progress, so use at your own risk as the schema is subject to change. If you would like to contribute, feel free to open a pull request that I can review.

## Credits
